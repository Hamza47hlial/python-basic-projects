## 📖 About

This repository is my learning journey with Python. Every time I build a new
program, practice a concept, or finish an exercise, I add it here.

The goals:

- Practice the fundamentals (variables, loops, functions, files, OOP...)
- Build small, working projects
- Track my progress over time

## 🚀 Getting Started

### Requirements

- Python 3.8 or higher ([download here](https://www.python.org/downloads/))
- Git

### Installation

```bash
# Clone the repository
git clone https://github.com/Hamza47hlial/python-basic-projects.git

# Go into the folder
cd python-basic-projects
```

### Run a project

```bash
# Projects in a single file
python Adventurer_Game.py

# Projects in a folder (run them from inside the folder so the imports work)
cd Calculator
python Calculator.py
```
